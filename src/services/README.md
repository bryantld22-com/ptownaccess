# Services

Reserved for later approved integrations. Build 5 uses local sample content and
device-only preview plans. AsyncStorage logic lives in `src/state/PreviewStore.tsx`;
there are no backend, authentication, payment, or database clients. Saved drafts
are not submitted to PTown, membership interests do not create enrollments, and
creative interests do not submit applications or notify PTown. Pathways are planned
content; there are no playable media, confirmed courses, or open applications.
